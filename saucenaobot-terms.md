SauceNaoBot ("the app") is a Reddit moderation helper. It looks up the image in
new link posts using the third-party SauceNAO service and replies with the
source it finds.

1. **Who may install it.** Moderators of a subreddit, using Reddit's Developer
   Platform. By installing you confirm you are authorised to configure the app
   for that community.
2. **You supply your own SauceNAO account.** You must enter your own SauceNAO
   API key in the app's settings. You are responsible for that key, for staying
   within SauceNAO's own terms and limits, and for any usage on it. The app does
   not provide a key.
3. **What the app does.** For each qualifying link post it sends the post's image
   URL and your API key to saucenao.com, then posts one comment as the app
   account and, if you configured flair IDs, changes the post flair. It does
   nothing to posts it cannot find a result for.
4. **Accuracy.** Results come from an automated image match. They can be wrong
   or missing. The app makes no guarantee that a result is the true source.
5. **Adult content.** Results can name or link adult works. The app is intended
   for communities that allow such content, and moderators are responsible for
   installing it only where appropriate.

   not affiliated with or endorsed by either.
